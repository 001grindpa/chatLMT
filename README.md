# chatLMT
## Intro
ChatLMT is the friendly, community‑focused assistant for the LMT DAO (Like‑Minded Troop). It helps members stay updated on web3 news, airdrops, trading tips, etc.

built using the Langgchain/Langgraph frameworks alongside tools and cmp servers integrated. ChatLMT provides an up-to-date response and keeps conversation flow consistent.
